## v1.7.3 更新內容

- 彈簧不會著火（釘板本來就不點）。只有一般平台會被點燃。踩到彈簧仍會彈起，待回血時也會回血。
- 清掉上一版「著火彈簧」相關程式。
- 她身下的平台都可以點，包含還沒捲進畫面、在畫面底下方最多 8 排（640 px）的平台。畫面外的平台不射火球，直接標記為著火，捲進來時已經在燒。她上方的平台、她站著的那塊，以及點燃前會捲到頂刺後面的，仍然不點。
- 落地範圍不變：畫面底下方超過 2 排的平台不能踩，掉出畫面的行為跟以前一樣。多出來的排只拿來點火。
- 吐火時火柱不蓋到龍頭的顎和牙；平台（含著火平台）畫在龍和火柱後面。只改畫圖順序和對位，龍的外觀和動畫不變。
- 已拿掉「最少被迫扣血最多 2 心」的上限，以及「點了會讓她無路可走就跳過」（同一個檢查）。音量維持 v1.7.2（全部 1.5 倍加壓縮器）。每次目標仍是 5～15 塊。
- 點著數量與實際扣心（真遊戲迴圈；2026-11-22，100 種子 × 第 50–700 層共 14 層；不含連續 3 次事件）。站著不動：1400 開局、871 局活到事件結束（62.2%；另 529 局事件結束前死掉），每次平均點著 9.847 塊（5–15）、0 塊 0%，達到 K 76.81%；一口火期間生命減少合計平均 5.286 心（1–9；含頂刺／釘板）。自動玩：1400 開局、1377 局活到結束（98.4%），每次平均 9.01 塊（4–15）、0 塊 0%，達到 K 58.24%；扣心平均 1.179（0–3）。彈簧 0 塊。對照 11-21 17:32 有上限的正式量測（300 種子、4200 開局）：站著不動當時 2574 事件／1626 局結束前死掉（活到結束 61.3%），點著平均 8.884；拿掉上限後活到結束的比例沒有大幅變少，點著數有上升（站著不動 8.884→9.847，自動玩 8.183→9.01）。

## v1.7.2 更新內容

- 全部音效音量提高為 1.5 倍（各音效之間的相對大小不變），並加上動態壓縮器，避免破音。
